# 2026-10-28

## 记账工具（React Native + Expo + TS + SQLite）

技术选型与落地情况：
- Expo SDK 58（RN 0.88 / React 19.3 / TS 6.0），脚手架由 create-expo-app blank-typescript 生成后平移到工作区根目录。
- 中文目录名会让 create-expo-app 报 "URL-friendly characters"，解法：先用 ASCII 名建子目录再平移；app.json 的 name 用中文「记账工具」，slug 保持 `ledger-app`。
- 路由用 expo-router（package.json main = expo-router/entry，app.json 加 scheme + plugins：expo-router / expo-sqlite / expo-sharing）。
- 数据层：expo-sqlite 单例 + PRAGMA user_version 迁移（src/db/schema.ts 的 MIGRATIONS 数组，只追加不改历史）。

关键设计决策：
- 金额一律整数「分」（amount_cents）。DDL 约束：`amount_cents > 0 AND CAST(amount_cents AS INTEGER) = amount_cents`，能拒绝 12.5 这类浮点写入，同时不会误杀驱动以 REAL 绑定的 1250。没有用 typeof(x)='integer'，因为驱动绑定类型不可控。
- 元→分解析按字符串拆位，禁用 parseFloat*100（src/lib/money.ts 的 parseAmountToCents）。
- 日期存 'YYYY-MM-DD' 文本（本地日期，无时区），字典序即时间序；GLOB 强校验格式，但 2026-10-32 这类非法日需业务层再校验。
- 分类存稳定 key（'food'），展示文案在 src/constants/categories.ts。
- CSV 带 BOM（Excel 中文不乱码）、CRLF、同时输出「金额(元)」与「金额(分)」两列、防公式注入前缀单引号、末尾追加合计行。

验证方式（可在无设备环境复用）：
- `npx tsc --noEmit` 通过；`npx expo export -p android` 打包通过。
- DDL 用 python sqlite3 跑过约束用例；money/csv 用 tsc 编译后用 node 跑 30 项断言。

状态：骨架 + 数据层完成，页面 app/index.tsx、app/new.tsx 仍是占位，等确认后再实现。
